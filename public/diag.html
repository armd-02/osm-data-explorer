🔍 ブラウザキャッシュ診断

まちデータ帳は GitHub Pages に公開されており、index.html は 10分間ブラウザにキャッシュされる仕様です（GitHub Pages はキャッシュ設定に 対応していないため）。デプロイ（更新）直後に通常リロードしても、 キャッシュの古い HTML・JS が読み込まれ、古いコードが動き続けることがあります。 このページで、あなたのブラウザがどの状態かを診断できます。

アプリのタブを確認する

まちデータ帳のタブで DevTools のコンソールを開き、次の一行を貼り付けて実行してください:

document.querySelector('meta[name="app-version"]')?.content ?? '旧HTML（機構なし）'

表示された値が上の「最新 app-version」と一致していれば最新です。 一致しない（または「旧HTML（機構なし）」）場合は、あなたのタブはキャッシュの古い版で動いています。 その場合は下のボタンでキャッシュをバイパスして開き直してください。

現在のタブが置換され、必ず新鮮な HTML・JS を取得します。 URL に保存されている検索条件（bbox・キーワード等）は引き継がれません。

その他の回避方法

  • ハードリロード: Ctrl+Shift+R（Mac: Cmd+Shift+R）
  • URL に任意の query を付加して開く: …/osm-data-explorer/?x=1
  • DevTools → Application → Storage → “Clear site data”
  • 10分待つ（キャッシュの有効期限が切れると次回リロードで最新版になります）
